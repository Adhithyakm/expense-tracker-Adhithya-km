# expense-tracker-Adhithya-km

A simple expense tracker built with HTML, CSS and JavaScript.

## Features

- Add, edit and delete income and expense transactions
- Amount, category (search / pick / create your own), date and note
- Totals for income, expenses and balance
- Filter by type and category, sort by date or amount, filter by month
- Monthly summary and category-wise expense pie chart
- Form validation with clear error messages
- Data saved in browser Local Storage
- Responsive layout (desktop and mobile)

## How to run

No installation needed. Download or clone the repo and open `index.html` in a browser.

## Notes

- The top totals always show all transactions; filters only change the list.
- Future dates are not allowed.
- Categories you create are saved separately for income and expense.
